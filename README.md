# Keg Despawn Timer (Blish HUD module)

Triple Trouble helper: This module contains helpful tools for commanders of Triple Trouble: This first release contains a tool for use by Cobalt Commanders to help with the Keg Despawn timer mechanic.

## Use
- Corner icon toggles the window.
- Start/Pause runs the 14:00 countdown; `<< 5s / << 1s / 1s >> / 5s >>` shift the clock; Reset clears everything.
- START Keg Run records the clock time; the despawn window opens 2:00 later on the clock (13:55 -> 11:55).
  STOP Keg Run records the stop time; the despawn window ends 2:00 later.
- Status: Despawns Clear (green), Despawns Soon (yellow) (30s from start of despawn window), In Despawns (red).
- Settings: Optional hotkeys for the timer and keg run.
